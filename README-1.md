# Task 8 – Sales Tracker

## Project
A simple Sales Tracker created in Excel with a Raw Data sheet and a Summary sheet.

## Features
- Total Sales calculated automatically using `Quantity × Unit Price`
- Daily, weekly, monthly, and overall sales summaries
- Product dropdown data validation
- Quantity and Unit Price validation
- Currency formatting in Indian Rupees
- Filter and frozen header row
- Product-wise sales summary and chart
- Manual verification of totals

## Verification
- Daily total for 01/09/2026: ₹1,04,000
- Overall total: ₹2,90,400

## Tools
Microsoft Excel

## Skills Demonstrated
Excel formulas, SUMIFS, SUMIF, data validation, data formatting, filtering, summary reporting, and basic data visualization.
